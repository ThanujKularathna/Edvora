# Online Learning Platform

## 📌 Project Overview
This project is a **web-based Online Learning Platform** developed as a **group project**.  
The platform allows students to access courses, manage their profiles, and interact with learning content, while administrators can manage users, courses, and system data efficiently.

The system is designed using **modern web technologies** with a focus on usability, scalability, and clean UI/UX.
